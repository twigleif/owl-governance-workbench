# Public feature baseline — draft 0.2 — example only

Transluce / Docent — simulated case

Record: SIM-DOCENT-REC-BASE-001. Research date: 2026-10-14. This is an exercise revision, not a Docent software release.

- [docent-introduction](https://transluce.org/docent): Docent describes ingestion, transcript analysis and inspection of matching results.
- [docent-docs-introduction](https://docs.transluce.org/introduction): Docent is described as an agent behavior analysis platform for investigating evaluation results.
- [analysis-plans](https://docs.transluce.org/analysis/analysis-plans): Current Analysis Plans combine deterministic DQL queries and language-model Reading steps.
- [reading-steps](https://docs.transluce.org/analysis/reading-steps): Reading context is configurable; metadata is excluded by default, and citations can be requested through the output schema.
- [dql-steps](https://docs.transluce.org/analysis/dql-steps): DQL is read-only querying; ID results can open the corresponding trace for inspection.
- [analysis-best-practices](https://docs.transluce.org/analysis/best-practices): The guidance recommends questions answerable from the traces and separates proposed hypotheses from validation.
- [docent-ingestion](https://docs.transluce.org/ingestion/quickstart): Evaluation logs can be ingested through the plugin, SDK and documented integrations.
- [permissions-sharing](https://docs.transluce.org/sdk/permissions): Collections support access checks and sharing with users, organizations or the public; sharing requires collection administration.

## Simulation boundary

Owners, risks, controls, assignments and planned work are invented for this example. Actual deployments, settings, effectiveness, completed assessments and issued decisions remain unprovided. The public-source Record remains Missing custody because exact upstream copies were not retained.
