## B1: described public capabilities

Docent analyses text-only agent transcripts to support agent-behaviour research.
Source: https://transluce.org/docent — Docent introduction: purpose and transcript analysis; accessed 2026-10-13.

Modern analysis plans combine deterministic DQL and Reading LLM steps.
Source: https://docs.transluce.org/analysis/analysis-plans — Analysis plans: DQL and Reading LLM steps; accessed 2026-10-13.

Reading steps use full message content by default; metadata is excluded unless configured. Context configuration is part of step/content identity. Citations require the applicable output-schema option.
Source: https://docs.transluce.org/analysis/reading-steps — Reading steps: context configuration, content identity and citations; accessed 2026-10-13.

DQL query results can expose clickable identifiers for read-only inspection.
Source: https://docs.transluce.org/analysis/dql-steps — DQL steps: clickable identifiers and read-only inspection; accessed 2026-10-13.
